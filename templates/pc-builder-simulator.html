🧾 ¿Qué es la BIOS?

Es el primer programa que corre tu PC al encenderla, antes que Windows, Linux o macOS. Revisa que el CPU, la RAM y las demás piezas respondan bien. Es como el portero de un edificio: revisa que todo esté en orden antes de dejar pasar al Sistema Operativo.

🖥️ ¿Cómo funciona el Sistema Operativo?

Cuando la BIOS confirma que el hardware está bien, el Sistema Operativo toma el control: organiza tus archivos, deja que abras programas, y "traduce" lo que tú haces (mover el mouse, escribir, jugar) para que el CPU, la RAM y la GPU lo entiendan. Es el gerente de toda la casa.

🪟🐧🍎 Windows, Linux y macOS

Windows: el más usado en casa y oficina; compatible con casi cualquier programa o videojuego. Lo hace Microsoft.

Linux: gratuito y de código abierto — cualquiera puede ver y modificar cómo funciona por dentro. Es el favorito para servidores de internet y para quienes quieren personalizarlo todo.

macOS: solo corre en computadoras Apple (Mac). Conocido por su diseño cuidado; muy usado por diseñadores y editores de video.

🛠️ MANTENIMIENTO DE UNA PC

Igual que un carro necesita servicio, una PC también necesita cuidados. Hay dos tipos: preventivo (evitar problemas) y correctivo (arreglar lo que ya falló).

🧹 PREVENTIVO — evitar que algo se dañe

🌬️
Limpiar el polvo
Cada 3-6 meses, con aire comprimido. El polvo tapa los ventiladores y sube la temperatura.
🧴
Cambiar la pasta térmica
Cada 1-2 años. Es la "crema" entre el CPU y el cooler que ayuda a transferir el calor.
🔄
Actualizar el sistema y los drivers
Corrige fallas de seguridad antes de que alguien las aproveche.
💾
Hacer respaldos (backups)
Copiar tus archivos importantes a otro disco o la nube, por si el SSD falla.
🔌
Usar un regulador o UPS
Protege la fuente de poder de subidas de voltaje y apagones.

🔧 CORRECTIVO — arreglar lo que ya falló

🦠
Quitar virus o malware
Con un antivirus, cuando el Sistema Operativo ya se infectó.
🔁
Reinstalar el Sistema Operativo
Cuando Windows/Linux/macOS ya no arranca bien o está muy dañado.
🧩
Reemplazar una pieza dañada
Por ejemplo, cambiar la RAM si hace "beep-beep" o la PSU si no da corriente.
🌡️
Corregir sobrecalentamiento
Revisar que el cooler esté bien puesto y girando si el CPU se calienta demasiado.
🔍
Diagnosticar con la BIOS
Si la PC no enciende, la BIOS (o sus pitidos de error) ayuda a saber qué pieza falla.

💡 Regla simple: preventivo = lo haces antes para que no pase nada malo. Correctivo = lo haces después, cuando algo ya se rompió.
